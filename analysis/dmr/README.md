# DMR Analysis

Differential methylation region (DMR) calling and downstream characterization
from Nanopore long-read bisulfite/modkit data.

## Overview

| Step | Directory | Tool(s) | Input | Output |
|------|-----------|---------|-------|--------|
| 1 | `01_prepare_beds/` | modkit | BAM + reference | CpG pileup BED |
| 2 | `02_call_dmrs/` | dmrseq, DSS | pileup BEDs | DMR BED/RDS |
| 3 | `03_integrate_signals/` | WGCNA | DMR calls | co-methylation modules |
| 4 | `04_annotate_dmrs/` | annotatr, clusterProfiler | DMR BED | annotated DMRs, pathway results |

## Inputs

- CpG pileup BEDs generated by `modkit pileup` (see `01_prepare_beds/`)
- Reference BEDs in `data/` (CpG islands, ASD gene coordinates — hg38)

Before running the DSS pipeline, place a samplesheet at:

    analysis/dmr/config/samplesheet.xlsx

Required columns: sample_id, barcode, diagnosis, family_id, dataset, bed_path

Your source spreadsheet (e.g. "sample_sheet.xlsx") can live
anywhere — export a filtered version with just these columns to samplesheet.xlsx.
The source file is gitignored; samplesheet.xlsx is committed.

## Outputs

Results are written to `results/` (gitignored). Each step directory contains
its own outputs under a matching subdirectory.

## Usage

Each step has its own submission script for SLURM. Run steps in order:

```bash
# 1. Prepare pileup BEDs
bash 01_prepare_beds/modkit_pileup_combined.sh

# 2. Call DMRs (submit to cluster)
sbatch 02_call_dmrs/submit_dmrseq.sh
sbatch 02_call_dmrs/submit_dss.sh

# 3. Integrate signals
Rscript 03_integrate_signals/wgcna_methylation.R

# 4. Annotate and run pathway enrichment
sbatch 04_annotate_dmrs/submit_heatmap.sh
Rscript 04_annotate_dmrs/annotate_dmrs.R
Rscript 04_annotate_dmrs/pathway_enrichment.R
```

## Configuration

`config/config.R` — shared R configuration (paths, sample metadata, palette).
Sourced at the top of each R script.

## Dependencies

| Tool | Version | Purpose |
|------|---------|---------|
| modkit | ≥0.3 | CpG pileup from BAM |
| dmrseq | Bioconductor | DMR calling |
| DSS | Bioconductor | DMR calling (alternative) |
| WGCNA | CRAN | Co-methylation network |
| annotatr | Bioconductor | Genomic context annotation |
| clusterProfiler | Bioconductor | Pathway enrichment |

See `../../workflow/envs/` for conda environment definitions.
